# OakWand

> Rig2Pixel 的公開部署鏡像。

**🎮 Live demo:** https://codingcatz.github.io/OakWand/

Rig2Pixel 是一套可在瀏覽器中使用的 2D 向量骨架 IK 動畫工具，
能將 SVG / 向量 / 分層圖片動畫轉換為多解析度 spritesheet。

本 repo 只包含部署產物（`gh-pages` 分支由 CI 自動更新），
原始碼維護在私有開發庫。

## 部署方式

```bash
# 在開發庫執行
npm run deploy
```

會把 `dist/` 推送到本 repo 的 `gh-pages` 分支，
GitHub Pages 自動發佈到上方 demo URL。
